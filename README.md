Open a notebook in [Google Colab](https://colab.research.google.com/) or Jupyter and run its cells. Common dependencies are NumPy, pandas, Matplotlib, and SciPy (see [requirements.txt](requirements.txt)). The covariance and efficient-markets notebooks use a public data source and require internet access.
